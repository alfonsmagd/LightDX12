Ldx12 Architecture

Read from top to bottom. The public user-facing API delegates to DeviceManager, DeviceManager owns the internal systems, and each system maps to a specific D3D12 or DXGI area.

RecordCommandBuffer records draws and states.
CloseThe associated command list is closed.
SubmitBatchPublic submission entry point.
ExecuteThe native queue executes the batch.
SignalThe native fence produces a SubmitHandle.
RecycleThe allocator and list return to the pool.

Exact descriptor ranges

CBV, SRV and UAV share one physical shader-visible heap. Samplers use a second shader-visible heap. RTV and DSV remain separate CPU-only heaps.

RTV heap · 256 default / maximum Descriptor storage capacity. A render pass can bind up to 8 color attachments simultaneously. The heap is CPU only and is not directly indexed by shaders.
DSV heap · 64 default / maximum Descriptor storage capacity. A render pass can bind one depth/stencil attachment. The heap is CPU only and is not directly indexed by shaders.
CBV
Constant Buffer View. Fixed public slots 1–5 and fixed engine slots 6–10.
SRV / UAV
Read-only and read-write resource views. Fixed slots cover common bindings; dynamic slots hold ordinary bindless resources.
Capacity is not simultaneous usage
The heaps store 256 RTV and 64 DSV descriptors, while one render pass can activate at most 8 RTVs and 1 DSV through CmdBeginRendering.
