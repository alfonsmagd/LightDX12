Ldx12 Architecture

Read from top to bottom. The public user-facing API delegates to DeviceManager, DeviceManager owns the internal systems, and each system maps to a specific D3D12 or DXGI area.

2. Command flow

AcquireRenderDevice returns a free command buffer.
RecordCommandBuffer records draws and states.
CloseThe associated command list is closed.
SubmitBatchPublic submission entry point.
ExecuteThe native queue executes the batch.
SignalThe native fence produces a SubmitHandle.
RecycleThe allocator and list return to the pool.

3. Resource lifetime

DescThe user describes a buffer, texture or sampler.

4. Bindless layout and root signature

What you can bind, where it lives, and the limits that matter when recording commands.

01

Root signature

Two root parameters. No descriptor tables.

Application constants b0
63 × 32-bit values · 252 bytes
CmdPushConstants()
Engine-reserved constant b1
Indirect draw index · written by CommandSignature

Direct heap indexing is enabled for resources and samplers.

Root signature flags CBV_SRV_UAV_HEAP_DIRECTLY_INDEXED SAMPLER_HEAP_DIRECTLY_INDEXED
02

Shader-visible heaps

The shader accesses two separate heaps directly by index.

Resources CBV, SRV and UAV share one heap

ResourceDescriptorHeap[index]
Your fixed slots
5 CBVs · slots 1–5
5 SRVs · slots 11–15
3 UAVs · slots 21–23
Dynamic resources
Allocated from slot 26. Use the descriptor index returned by Ldx12; do not choose these slots manually.

CBV: constant buffers · SRV: read-only views · UAV: read/write views. Engine slots are reserved.

Descriptor ranges

One shared CBV / SRV / UAV heap · maximum capacity: 4,096 descriptors.

SlotsDescription
0Invalid descriptor · reserved as the null slot
1–5User CBV · constant buffer views
6–10Engine CBV · internal constant buffers
11–15User SRV · read-only resource views
16–20Engine SRV · internal read-only views
21–23User UAV · read/write resource views
24–25Engine UAV · internal read/write views
26–4,095Dynamic bindless resources · 4,070 slots by default

Samplers A separate heap for sampling settings

SamplerDescriptorHeap[index]
Built-in · slots 0–3
LinearClamp · LinearWrap · PointClamp · ShadowComparison
Your samplers · slots 4–7
Up to 4 custom samplers. Use CreateSampler() and GetSamplerIndex().

A destroyed sampler's slot remains reserved until its pending GPU work completes.

Descriptor ranges

Separate shader-visible sampler heap · 8 descriptors.

SlotsDescription
0–3Built-in samplers · LinearClamp, LinearWrap, PointClamp and ShadowComparison
4–7Custom samplers · 4 runtime slots available to the application
03

Render attachments

CmdBeginRendering() selects these through the framebuffer. Their heaps are CPU-only.

Color · RTV
Up to 8 color attachments per render pass.
Depth / stencil · DSV
Up to 1 depth/stencil attachment per render pass.

Select attachments in the framebuffer. Shaders do not access RTV or DSV descriptors through a heap index.
